Hypercat documentation
======================

**Hypercat** is a Python package for working with the CLUMPY hypercubes of AGN
torus model images. It provides N-dimensional interpolation over hundreds of
thousands of pre-computed images, physical unit handling, single-dish and
interferometric observation simulation, morphological analysis, and an optional
interactive GUI.
